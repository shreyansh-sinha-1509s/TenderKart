🏛️ Kimball Star Schema Architecture for Power BI Ingestion: 
               ┌───────────────────────┐             ┌─────────────────────────┐
               │     dim_contractors   │             │       dim_tenders       │
               ├───────────────────────┤             ├─────────────────────────┤
               │ Contractor_Code (PK)  │             │ Tender_ID (PK)          │
               │ Name, Company, Email  │             │ Tender_Name, Department │
               │ Assigned_Cluster      │             │ Category, Location, Cost│
               └───────────┬───────────┘             └────────────┬────────────┘
                           │ 1                                    │ 1
                           │                                      │
                           │ N                                    │ N
               ┌───────────┴──────────────────────────────────────┴────────────┐
               │                      fact_applications                        │
               ├───────────────────────────────────────────────────────────────┤
               │ Application_Code (PK)                                         │
               │ Contractor_Code (FK) ─────────► dim_contractors.Contractor_Code│
               │ Tender_ID (FK)       ─────────► dim_tenders.Tender_ID         │
               │ Applied_On (FK Date)                                          │
               │ Bid_Amount_Crores (Measure / Metric)                          │
               │ Application_Status, Outcome ('Won' / 'Lost' / 'Pending')      │
               └───────────────────────────────────────────────────────────────┘
📘 Step-by-Step Instructions to Connect in Power BI Desktop:
  1. Download the four CSV files above into your local project directory.
  2. Open Power BI Desktop → Click Get Data → Select Text/CSV → Load each file.
  3. In the Model View, connect fact_applications[Contractor_Code] to dim_contractors[Contractor_Code] (1-to-Many).
  4. Connect fact_applications[Tender_ID] to dim_tenders[Tender_ID] (1-to-Many).
  5. Create DAX Measure for Win Rate: Win Rate % = DIVIDE(CALCULATE(COUNT(fact_applications[Application_Code]), fact_applications[Outcome] = "Won"), CALCULATE(COUNT(fact_applications[Application_Code]), fact_applications[Outcome] IN {"Won", "Lost"}), 0) * 100.
Curriculum Mapping Third-Year Information Technology Engineering

Academic Syllabus & Laboratory Course Mapping

B.Tech IT

TenderKart was engineered to demonstrate concrete implementation of standard computer engineering syllabus laboratory experiments:

🧪 Exp 1: Web Analytics Instrumentation

Implementation of asynchronous client-side interaction telemetry (views, searches, filters) persisting into relational SQLite event tables without rendering overhead.

🧪 Exp 2: Data Preprocessing & Scaling

Handling nulls, feature selection, and Z-score normalization (StandardScaler) ensuring multi-crore bid metrics and percentage rates possess balanced unit variance.

🧪 Exp 3: K-Means Clustering Algorithm

Application of scikit-learn K-Means++ clustering ($k=3$), inertia WCSS minimization, silhouette score calculation, and behavioral contractor segmentation.

🧪 Exp 4: Association Rule Mining (Apriori)

Market basket analysis of co-bidding patterns across infrastructure verticals, computing Support, Confidence, and Lift for cross-sector affinity rules.

🧪 Exp 5: Star & Snowflake DW Schemas

Design of Kimball Star Schemas separating fact records (events, bids) from dimensions (tenders, contractors, dates) ready for Power BI OLAP modeling.

🧪 Exp 6: REST APIs & Role Authorization

Node.js + Express REST routing with JWT authentication, parameterized SQL queries against SQLite, and role isolation for Contractor, Manager, and Admin.
