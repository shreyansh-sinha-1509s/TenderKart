MISSION STATEMENT

Centralizing Public Sector Infrastructure Procurement

TenderKart is a centralized tracking prototype designed to assist contractors, engineers, and suppliers discover and manage urban growth opportunities like highways, storm networks, treatment plants, and smart lighting grids.

Core Features & Challenges Solved

  • 🧭
    Unified Discovery Feed Instead of digging through 50+ scattered municipal boards, view all active tenders in one single screen.
  • 🤖
    AI Specs Extraction Click the summarize button to parse the outlay budget, submission deadline, qualifications, and core scopes automatically.
  • 📂
    Digital Filing Checklists Inspect dynamic required documents grids to avoid rejection because of missing certifications.

Academic Project Info

This project is designed as an interactive GovTech prototype demonstrating database queries, API routing, and modern frontend styles.

FRONTEND LAYERS HTML5, CSS3, Vanilla JS
BACKEND ENGINE Node.js, Express.js
DATABASE FILE SQLite (sqlite3 driver)
AI PARSER Gemini API / Smart Local Fallback
